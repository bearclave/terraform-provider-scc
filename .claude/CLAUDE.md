# terraform-provider-scc

Documentation is in `README.md`. The organisation standards are in
`.claude/rules/` (managed copies from `bearclave/governance`). This file holds
only what is specific to this repository.

## This repository

- **Public**, permanent fork of terraprovider/terraform-provider-scc, published
  to the Terraform Registry as `bearclave/scc`; not contributed upstream.
  Nothing about a tenant goes here.
- **What a merge does:** nothing is deployed; the owner merges
  (`workflow.md`). A release is cut by the owner afterwards.
- **Local checks before a pull request:** `go vet ./...`, `go test ./...`,
  `go run ./cmd/gen-tf` leaves no diff, `cd tools && go generate ./...` leaves
  no diff in `docs/` (CI runs the same plus golangci-lint).
- **Review:** `/code-review`.
- **Do not touch:** `internal/provider/*_resource.go`, `*_data_source.go` and
  `zz_generated_*.go` (generated: change `cmd/gen-tf` or the `overrides*.go`
  files) and `docs/` (generated by tfplugindocs).
- **Releases:** the owner, `tools/release.sh vX.Y.Z` (signed tag, goreleaser,
  key from Key Vault). Never from a workflow.
